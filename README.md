### 🚀 About Me

I'm an **AI/Software Engineer** currently building **RESOLVE**, an AI-native NLP-to-SQL agent, as an **AI Engineer at Proliant Data**. Previously a **Research Assistant at USC Viterbi** working on agentic AI frameworks and multi-agent systems, and a **Software Engineer at HubSpot** shipping AI-powered features used across the Workflow Action Builder.

- 🔭 **Currently building:** RESOLVE — a 28-tool autonomous agent with hybrid RAG (FAISS + Neo4j) that grounds every generated SQL query in enterprise data
- 🌱 **Currently exploring:** multi-agent orchestration, prompt caching strategies, and agent safety/cost guardrails
- 🎓 **Education:** M.S. Computer Science, University of Southern California (2023 – 2025)
- 💬 **Ask me about:** LLMs, RAG pipelines, agentic systems, and full-stack AI products
- 📫 **Reach me:** sondurip@usc.edu
